Forecast Arena is a high-stakes, competitive prediction market platform built for users to forecast real-world events. Users can place bets using virtual coins, climb a dynamic competitive leaderboard, and earn status badges based on their predictive accuracy.

<b>Key Features</b>

Prediction Marketplace: Dynamic odds generation based on real-time betting pools.

Competitive Leaderboard: Real-time rank calculation based on current coin balances.

Account Integrity: Secure registration and user authentication.

Responsive Design: Optimized experience for both desktop and mobile users.

Tech Stack

Languages: HTML5, CSS3, Vanilla JavaScript.

Design: Custom responsive grid system with mobile-first media queries.
